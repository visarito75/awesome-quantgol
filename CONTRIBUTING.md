# Cómo contribuir

¡Gracias por sumar recursos! Para que la lista siga siendo útil:

1. **Un recurso por propuesta** (issue o pull request).
2. **Formato de cada entrada**, en la sección que corresponda:
   ```
   - [Nombre](https://enlace) - qué aporta, en una frase. Plan gratuito o de pago y su límite principal.
   ```
3. **Qué entra:** fuentes de datos de fútbol, conjuntos de datos históricos, modelos y artículos, librerías y
   herramientas de evaluación de pronósticos de goles.
4. **Qué no entra:** casas de apuestas, comparadores de cuotas, «tipsters» de pago y enlaces de afiliados.
5. **Comprueba antes de proponer:** que el enlace funciona, que el recurso sigue mantenido y que el límite del plan
   gratuito es el actual.
6. Mantén el orden alfabético dentro de cada sección y la descripción en una sola línea.

Los enlaces se revisan solos cada semana; si uno se rompe, se abre un aviso para corregirlo o quitarlo.
